## 🏗️ System Overview

The corporate world runs on blind trust and legacy PDFs. Businesses routinely sign 50-page vendor Master Service Agreements (MSAs) without forensic review, leaving them exposed to toxic non-competes, asymmetric IP assignments, and uncapped indemnifications. 

**Vigilate** is a Legal Surveillance and Clause Extraction engine built to hunt down these liability traps. Powered by a 600k character context window and Llama-3.3-70B, it ingests massive, unstructured legal documents and performs deep-clause extraction, surfacing the absolute worst risks into a plain-English 1-10 Risk Scorecard before a signature is ever applied.

## ⚡ Core Architecture

Vigilate is designed with a High-Tech Minimalist engineering philosophy: Absolute Security, Bare-Metal Optimization, and Workflow-First logic.

### Tech Stack
* **Frontend Command Center:** React (Vite), Tailwind CSS, Lucide Icons, React Router.
* **Backend Infrastructure:** Django, Django REST Framework, SQLite/PostgreSQL.
* **AI Processing:** Llama-3.3-70B via SambaNova APIs.
* **Financial Pipeline:** Secure webhook integration via Dodo Payments.
* **Document Parsing:** `PyPDF2` and `python-docx` for layer extraction.

### Feature Arsenal
* **Deep-Clause Extraction:** Bypasses "Lost in the Middle" syndrome on 100+ page PDFs.
* **Risk Scorecard Engine:** Algorithmically scores contracts from 1 (Safe) to 10 (Predatory).
* **Tiered Authorization:** Token-based DRF authentication gating Free (Reconnaissance) and Pro (Command Center) tiers.
* **Cryptographic Webhooks:** Server-side signature unwrapping to verify Pro upgrades instantly.
* **PDF/TXT Intelligence Export:** Client-side generation of forensic reports using `jsPDF`.

## 🔒 Security & Data Doctrine

Enterprise data is a weapons-grade asset. Vigilate operates on strict data minimization principles:
1. **Zero-Retention Processing:** Uploaded PDFs and DOCX files are processed in memory and immediately purged from the server post-extraction.
2. **AI Privacy Wall:** AI inference providers are contractually blocked from using Architech transmission data to train public models.
3. **Exact-Match Billing:** API spend is calculated dynamically via `DecimalField` token counting to prevent microscopic rounding drift over thousands of inferences.
